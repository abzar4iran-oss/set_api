# Lesson media (static)

Files live at `public/media/voice/` (mirror of the app's `assets/lesson/voice`).

Sync from the Expo app:

```bash
cd D:\Al_Najmo_Thagheb
yarn sync:media
```

Public URL example:

`http://localhost/api/public/media/voice/lesson_01_Arabic_Alphabet/1.mp3`

No PHP route required — Apache serves existing files under `public/`.
